# Dataset card

## Toy classification fixture

- **Name:** BioAudit toy classification sequences
- **Task:** Three-class sequence label (`nucleus`, `cytoplasm`, `membrane`)
- **Origin:** Generated by `bioaudit.dataset.generate_toy_classification_records`
- **Size:** 21 records (6 families × 3 near-identical members, plus 3 singletons)
- **License:** Same MIT license as BioAudit code; data are synthetic
- **Must not be used as:** evidence of biological performance, a paper reproduction, or a substitute for DeepLoc/UniProt localization data
- **Why it exists:** Offline tests of validation, homology-aware splitting, and the experiment CLI

## UniProtKB reviewed human proteins (optional)

- **Query:** `(reviewed:true) AND (organism_id:9606)`
- **Access:** `scripts/prepare_dataset.py --source uniprot` (bounded `--limit`, timeout, manifest)
- **Terms:** UniProt license; this repository does not commit the FASTA
- **Not used as:** the default supervised benchmark (no canonical classification label)

## Candidate public benchmark (not downloaded)

Protein subcellular localization on a public set with a clear citation (for example DeepLoc 2.0 or UniProt location annotations) remains the intended real experiment. Confirm license and size before downloading.
